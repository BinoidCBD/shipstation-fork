## How it fits together
The plugin's core integration is managed by `class-wc-shipstation-integration.php`, which registers hooks, initializes the REST API, and handles authentication via `class-auth-controller.php`. This class also defines the main API client `class-wc-shipstation-api.php` for communicating with ShipStation.  

The REST API for orders is handled by `class-orders-controller.php`, which exposes endpoints like `/wc-api/v3/orders` for order synchronization. It relies on `class-order-util.php` to normalize order data between legacy and HPOS storage formats, ensuring consistent processing.  

Order exports to ShipStation are orchestrated by `class-wc-shipstation-api-export.php`, which uses `class-order-util.php` to prepare data and executes bulk exports. The WPCOM transport scaffold in `class-wpcom-connection.php` provides an experimental feature flag (`WC_SHIPSTATION_WPCOM_TRANSPORT`) for alternative connectivity, though it’s not yet active.  

Authentication flows use `class-auth-controller.php` to manage OAuth2 redirects and token storage, while `class-main.php` serves as the plugin’s bootstrap, loading REST API loaders and initializing the main integration class.
